# Testbenches

Simulation testbenches for the core, one folder per area, each with its
runner script; `run_all.sh` is the gate before a synthesis, `run_long.sh` runs
the long floppy suites, and `stubs/` holds the simulation stubs of the Xilinx
libraries.
